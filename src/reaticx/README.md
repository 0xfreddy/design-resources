# Reaticx source provenance

These are the complete source files published on eight Reaticx component pages, retrieved on 2026-09-29. ArcList's index is also byte-identical to the user's pasted source. SearchBar and RadiantButton start from the latest user attachments, with their supporting files from the official pages. The previous integration had invented helper functions and constants; those have been replaced with the published files.

`provenance.json` records upstream and installed SHA-256 hashes. Run `node scripts/check-reaticx.mjs` to verify the reviewed installation. ArcList, Checkbox, FanMenu, ExpandableView, and SplitView's implementation files are unchanged from the provided source. Their geometry, constants, spring configurations, and compound APIs are the original ones. Checkbox's three files are byte-identical, including the paths and stroke animation; `ResourceCheckbox.tsx` uses the press springs from the supplied example.

## Explicit compatibility changes

- `search-bar/SearchBar.tsx`: adds a `renderAction` slot in the original Cancel position for RadiantButton, collapses that slot's width when unfocused, labels the clear button, and updates only ref/BlurView TypeScript types for the installed React Native version. All original focus, clear, text and width animations are retained. `SearchBar.types.ts` exposes this slot and standard TextInput props so Enter submits and the input has an accessible label.
- `radiant-button/index.tsx`: adds a button role/label/disabled accessibility state and cancels looping animations on unmount. Its Skia shader, theme helpers, spring settings, press effect and rendering remain from the supplied component.
- `split-view/types.ts`: uses `ReturnType<typeof Gesture.Pan>` because Gesture Handler 3's exported `PanGesture` type refers to its newer API. No gesture implementation was changed.
- `apple-intelligence/index.tsx`: corrects the View ref type for React Native 0.87, supplies Skia's required browser snapshot callback, and stops animations/releases the snapshot after unmount. The original shader, uniforms, constants, context, and animation logic remain intact.
- `apple-intelligence/snapshot.web.ts`: supplies the DOM screenshot that Skia requires on web. Images are excluded from the snapshot to avoid cross-origin canvas tainting. The app displays the real screenshot as normal HTML and clips the shader overlay to the border, keeping controls and text live underneath.
- Vite runs the Worklets Babel plugin, resolves `.web` entry points, and prebundles Skia's optional Reanimated imports. CanvasKit is loaded once on demand for the RadiantButton or expanded previews; the search action remains usable while it loads.
- The existing Expo browser adapters remain for blur, symbols, icons, and haptics. Blur now follows the supplied intensity instead of being permanently blurred.
- `src/shims/react-native-svg.ts` extends the dependency's web Path with the missing native `getTotalLength` and mount-layout callback. It measures the actual SVG path, allowing the unchanged Checkbox to animate its stroke on web. SVG rendering and all timing remain in the original library/component.
- React StrictMode is disabled at the app root because Skia 2.13's web picture lifecycle throws during development double-mount. Browser tests exercise mount, close, and reopen instead.

App-specific theme colors, dimensions, fan direction, and navigation typography are passed through the components' public props in `App.tsx` and `ResourceControls.tsx`. The globe dock and hover preview use body portals to escape scroll-container clipping. Reduced-motion previews skip the shader overlay.

`ResourceNavigation.tsx` presents categories and all their subcategories through one original ArcList, without collapsed groups. Its public content-container padding prop removes the large empty edges. A context adapter follows the resource pane's active section with one interruptible spring, coalescing rapid changes without locking independent navigation scrolling. Radius 680, 46px row spacing, minimum opacity 0.55 and haptics are passed through the public props. The actual directory section is highlighted orange. The browser haptics adapter calls the Vibration API when available after user interaction. Browsers/devices without vibration support do not produce physical feedback. The FanMenu source remains installed but its view-switching UI has been removed at the user's request.

`RadiantAction.tsx` uses the supplied RadiantButton with a black background and the user's updated softer orange accent, dot opacity 1, dots enabled, glow width 0.5 and shimmer opacity 0.5 for both Pick resources and Share the stack. Full-width desktop actions use the sample's 250px width and 17px text; the search action gets smaller dimensions on narrow screens. Fonts fall back to the system face because the sample's licensed font files were not supplied. Reduced-motion settings disable shimmer/breathing/glow.

The application shell is fixed to the viewport. `StackPaneSizing.tsx` uses the original SplitView context to expand the drawer after the first selection and compact it when empty; dragging still uses the original gesture implementation. Selected resources appear in keyboard-accessible browser tabs that cannot shrink away. Sharing opens a native modal with a read-only tab preview, Twitter handle and persisted share link. Globe width/height stay equal independently of the expandable container's animated dimensions.

The carousel has no visible heading, resource counts, or vertical content padding. Its follow animation clamps to the actual scrollable range so the final items remain reachable on narrow screens. Resource rows show only their specific notes, not repeated category descriptions. Sidebar border segments are inset and interrupted around navigation and the visitor dock. The split handle is white in dark mode and dark in light mode for contrast.

`StackFlight.tsx` animates an opaque favicon for 1.15 seconds, measuring its real tab destination each frame while the drawer settles. The destination icon is hidden until landing; reduced-motion selections skip the flight. `JevSearch.tsx` hides the original leading icon using public props and opts out of browser autofill. Browser- or extension-owned autofill controls cannot be universally suppressed by page code. `IntelligenceFrame.tsx` passes a slower orange/yellow/red palette to the original shader. The visitor dock measures the sponsor card for both collapsed and expanded width, with 8px corners. Dark mode is the default; explicit saved theme preferences are retained.
